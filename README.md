# Banking System — C++

An Object-Oriented Banking Management System in C++ that allows users to manage customers, accounts, deposits, withdrawals, fund transfers, and transaction history logs[cite: 1].

Developed as part of the **CodeAlpha C++ Programming Internship**[cite: 1].

---

## Features
* **OOP Architecture:** Uses `Customer`, `Account`, `Transaction`, and `BankingSystem` classes[cite: 1].
* **Deposit & Withdrawal:** Securely updates balances and logs transaction records with timestamps[cite: 1].
* **Fund Transfers:** Transfers money between two active accounts with validation checks[cite: 1].
* **Transaction History:** Displays dated audit logs of all past activities per account[cite: 1].
